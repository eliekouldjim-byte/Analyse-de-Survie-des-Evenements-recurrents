# Analyse-de-Survie-des-v-nements-r-currents
L’analyse de survie des événements récurrents dans le cadre des études longitudinales. 
L'Accent est mi sur sur :  les modèles adaptés aux événements répétés chez un même individu ; les limites du modèle de Cox classique, notamment l’ignorance de la corrélation intra sujet ; la comparaison de modèles étendus (Andersen–Gill, PWP, marginal, fragilité).
